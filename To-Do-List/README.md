# 📝 To-Do List

A simple and responsive To-Do List web application built using **HTML, CSS, and JavaScript**. This project helps users manage their daily tasks by adding, editing, completing, and deleting tasks.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Filter tasks:
  - All
  - Active
  - Completed
- 🧹 Clear all completed tasks
- 💾 Tasks are saved using Browser LocalStorage
- 📱 Responsive design for mobile and desktop
- ⌨️ Add tasks using the Enter key

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and DOM manipulation
- **LocalStorage** – Persistent task storage
