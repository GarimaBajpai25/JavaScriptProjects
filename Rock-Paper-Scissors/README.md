🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. The player competes against the computer, which randomly selects Rock, Paper, or Scissors.

🚀 Features

- 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
- 🤖 Random computer choice
- 🏆 Automatic winner detection
- 📊 Real-time score tracking
- 🔄 Reset game functionality
- 📱 Responsive design for mobile and desktop
- ✨ Simple and user-friendly interface

🛠️ Technologies Used

- HTML5 – Structure of the game
- CSS3 – Styling and responsive design
- JavaScript – Game logic and score management

🎯 Game Rules

Player| Computer| Result
Rock 🪨| Scissors ✂️| Player Wins
Paper 📄| Rock 🪨| Player Wins
Scissors ✂️| Paper 📄| Player Wins
Same Choice| Same Choice| Draw

If the player chooses any other combination, the computer wins.
